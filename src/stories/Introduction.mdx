# XLP UI - Component Library

Welcome to **XLP UI**, a modern React component library built on top of [Chakra UI](https://chakra-ui.com/).

## 🚀 Features

- **Built on Chakra UI v3** - Leverages the power and flexibility of Chakra UI
- **TypeScript First** - Full TypeScript support with strict typing
- **Dark Mode Support** - Built-in light/dark mode switching
- **Accessible** - WAI-ARIA compliant components
- **Customizable** - Easy theming with design tokens
- **Tree-shakeable** - Import only what you need

## 📦 Installation

```bash
npm install xlp-ui @chakra-ui/react @emotion/react
```

## 🏁 Quick Start

Wrap your application with `XlpProvider`:

```tsx
import { XlpProvider, XlpButton } from 'xlp-ui';

function App() {
  return (
    <XlpProvider>
      <XlpButton colorPalette="blue">
        Hello World
      </XlpButton>
    </XlpProvider>
  );
}
```
